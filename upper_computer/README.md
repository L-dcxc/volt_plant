# 植物记录仪上位机

STM32 植物记录仪的 PyQt5 上位机，通过 Modbus RTU（串口）与设备通信。

## 功能

- **连接**：串口选择、波特率、从机地址，连接后显示设备信息
- **时钟**：读取设备 RTC、设为系统时间、手动设定
- **运行控制**：上传程序（写全配置+保存）、取回程序（读全配置）、启动/暂停采集、保存/恢复出厂/软件复位、系统状态查看
- **通道**：勾选通道并读取所选通道的当前电压（µV）和原始码
- **配置**：系统配置 + 16 通道完整参数编辑
- **文件下载**：目录列举可用，YMODEM 字节流传输待固件实现（界面占位）

## 安装

需要 Python 3.8+。

```bash
cd upper_computer
pip install -r requirements.txt
```

## 运行

```bash
python run.py
```

## 使用流程

1. 打开「连接」页，选择串口（默认波特率 115200，地址 1），点「连接」。连接成功会显示设备 ID。
2. 「运行控制」页点「取回程序」把设备当前配置读到「配置」页。
3. 在「配置」页修改参数后，回「运行控制」页点「上传程序」写入并保存。
4. 「通道」页勾选通道点「读取所选通道」查看实时测量值。
5. 「时钟」页可同步设备时间。

## 设备通信参数

- 串口：115200 8N1，无流控
- 协议：Modbus RTU，默认从机地址 1
- 支持功能码：FC03 / FC04 / FC06 / FC16
- 寄存器映射见项目根目录 `modbus_register_map.md`

## 项目结构

```
upper_computer/
├── run.py                  入口
├── requirements.txt        依赖
└── app/
    ├── main_window.py      主窗口 + 共享上下文
    ├── modbus_client.py    Modbus 通信封装
    ├── registers.py        寄存器地址常量 + 编解码

```

## 说明

- 修改 Modbus 地址或波特率后需保存并复位设备才生效，且上位机需用新参数重新连接。
- 通道配置的「负输入」选 `AVSS(17)` 表示单端测量。
- 「上传程序」会写入全部 16 通道配置，非法组合（如正负输入相同）会被固件在保存时拒绝（返回异常）。
